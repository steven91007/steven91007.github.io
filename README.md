# steven91007.github.io

Personal site of Chi-Yi (Amo) Hsu — built with [Astro](https://astro.build), deployed to GitHub Pages
by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
```

Add a project: create `src/pages/projects/<slug>.astro` and list it in `src/pages/projects/index.astro`.
Only publish work-project details that your employer has cleared.
